# LegionIO Documentation Site

The public documentation website for LegionIO, built with Jekyll and served via GitHub Pages.

**Live site**: https://legionio.dev

## Development

```bash
bundle install
bundle exec jekyll serve --livereload
```

The site will be available at `http://localhost:4000`.

## Structure

- `index.md` — Home page
- `architecture.md` — Architecture deep-dive
- `getting-started/` — Quickstart guides
- `extensions.md` — Extension ecosystem
- `philosophy.md` — Project philosophy
- `compatibility.md` — Version compatibility matrix
- `enterprise.md` — Enterprise features and deployment
- `schema.md` — Settings JSON schema reference
- `assets/` — CSS, JS, images, interactive visualizations
- `_config.yml` — Jekyll configuration (just-the-docs theme)
